# BukuMateri

**Buku Materi Digital — Flipbook HTML5**  
Millenial Academy | v1.0.0

## 🚀 Demo

Buka langsung di GitHub Pages:  
https://sdkv1.github.io/BukuMateri

## 📖 Fitur

- **Flip 3D Realistis** — Animasi halaman menggunakan CSS 3D transforms
- **Responsive** — Desktop, tablet, dan mobile
- **Touch & Swipe** — Navigasi swipe untuk perangkat mobile
- **Keyboard Navigation** — Arrow keys, Home, End, Space
- **Zoom In/Out** — Kontrol zoom halaman
- **Fullscreen Mode** — Mode layar penuh
- **Daftar Isi (TOC)** — Navigasi cepat ke bab
- **Thumbnail Panel** — Preview semua halaman
- **Progress Indicator** — Dots navigation & page counter
- **10 Halaman** — Cover, 3 chapter, 5 konten, back cover

## 🛠️ Teknologi

- HTML5 Semantic
- CSS3 (3D Transforms, Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display + Inter)

## 📂 Struktur

```
BukuMateri/
├── index.html          # Entry point
├── css/
│   └── style.css       # Styling & animasi
├── js/
│   └── flipbook.js     # Engine flipbook
└── README.md           # Dokumentasi
```

## 📱 Konten

Buku materi ini berisi panduan **Teknik Perbaikan Handphone**:

1. **Cover** — Judul & branding Millenial Academy
2. **Bab 1: Pengenalan Komponen** — SoC, RAM, PMIC
3. **Bab 2: Troubleshooting** — Matot, short detection, bootloop
4. **Bab 3: Advanced Repair** — Reballing BGA, jumper
5. **Back Cover** — Info & social links

## 📝 Cara Pakai

1. Clone repo:
   ```bash
   git clone https://github.com/sdkv1/BukuMateri.git
   ```
2. Buka `index.html` di browser
3. Atau deploy ke GitHub Pages

## 🎨 Kustomisasi

Edit file `js/flipbook.js` → array `pagesData` untuk mengganti konten.  
Edit `css/style.css` untuk mengubah tema warna.
